# Proposal

## Why

ИИ-агент, консультирующий по инвестициям в российский рынок (акции, облигации, фонды, индексы), не имеет доступа к актуальным рыночным данным и вынужден полагаться на память модели, которая устаревает и ошибается в тикерах и ценах. Нужен MCP-сервер над публичным API Московской биржи (ISS), через который агент (отдельный Python-проект на MCP SDK) получает цены, историю и находит бумаги по названию. Одновременно это выполняет учебную цель: зарегистрировать инструменты, описать входные параметры, вернуть результат и вызвать их из агента.

## What Changes

- Новый Python-проект `mcp-moex`: MCP-сервер на официальном `mcp` SDK (`MCPServer`, бывший FastMCP), доступ к ISS через `httpx` (async), Pydantic-модели входа и выхода.
- Три инструмента, все только для чтения (`readOnlyHint`):
  - `search_securities` — поиск бумаги по названию, тикеру или ISIN с фильтром по классу актива.
  - `get_current_price` — актуальная цена бумаги (данные ISS с задержкой около 15 минут, задержка явно указывается в ответе).
  - `get_price_history` — свечи за период с серверной сводкой (первая и последняя цена, минимум, максимум, изменение в %).
- Единый резолвер `secid -> engine/market/board`, чтобы агенту не приходилось знать устройство площадок ISS.
- Нормализация единиц: облигации в % от номинала пересчитываются в рубли и дополняются НКД и доходностью, индексы отдаются в пунктах.
- Запуск локально с этой машины: транспорт `stdio` по умолчанию, Streamable HTTP на `127.0.0.1` как опция, логи только в stderr, точка входа `mcp-moex`.
- Смоук-клиент на MCP SDK (`stdio_client`), который запускает сервер, вызывает `list_tools` и все три инструмента.
- Не входит в изменение: удалённый деплой на VPS (отказались из-за риска блокировки ISS с зарубежного IP), авторизация и TLS, сам агент, история по снятым с торгов бумагам, фьючерсы, опционы и валютный рынок, корректировка цен на сплиты и дивиденды.

## Capabilities

### New Capabilities
- `moex-security-search`: поиск бумаг на Мосбирже по названию, тикеру или ISIN, с фильтром по классу актива и исключением снятых с торгов бумаг и индикаторов.
- `moex-current-price`: получение актуальной цены бумаги (акции, облигации, фонды, индексы) в нормализованном виде с меткой времени и признаком задержки.
- `moex-price-history`: получение свечей за период с выбором интервала, пагинацией ISS и серверной сводкой.
- `mcp-server-runtime`: регистрация инструментов, описание входных параметров, формат результатов и ошибок, транспорты, логирование и проверка смоук-клиентом.

### Modified Capabilities

Нет: в проекте пока нет существующих спецификаций.

## Impact

- Новый код: пакет `mcp-moex` (сервер, клиент ISS, резолвер, модели, смоук-клиент), `pyproject.toml` под `uv`.
- Новые зависимости: `mcp`, `httpx`, `pydantic`; для тестов `pytest` и `pytest-asyncio` (или эквивалент).
- Внешняя система: публичный ISS `https://iss.moex.com/iss` (без ключа, данные с задержкой; недокументированные лимиты, поэтому нужен короткий кэш).
- Контракт с внешним проектом агента: команда запуска `uv run --directory <путь к проекту> mcp-moex` и формат результатов инструментов (`structuredContent` и текстовый JSON).
