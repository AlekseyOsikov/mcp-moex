# Spec Delta

## MODIFIED Requirements

### Requirement: Регистрация инструментов
Сервер SHALL публиковать через `list_tools` по умолчанию ровно три инструмента: `search_securities`, `get_current_price` и `get_price_history`. Каждый инструмент MUST иметь текстовое описание, объясняющее для чего он нужен и когда его применять, и JSON-схему входных параметров с типами, описаниями, допустимыми значениями перечислений, значениями по умолчанию и границами. Все три инструмента MUST быть помечены как только читающие (`readOnlyHint`), сервер SHALL NOT выполнять никаких действий, изменяющих внешние системы. Только при явном включении режима расписания (флаг `--watch-db`) сервер SHALL дополнительно публиковать шесть инструментов расписания (см. возможность `moex-price-watch`): они изменяют лишь локальное хранилище сервера, не помечены как только читающие и не относятся к трём инструментам чтения, чьё поведение режим не меняет.

#### Scenario: Клиент запрашивает список инструментов
- **WHEN** клиент вызывает `list_tools` у сервера, запущенного без `--watch-db`
- **THEN** ответ содержит три инструмента с именами `search_securities`, `get_current_price`, `get_price_history`
- **AND** у каждого есть описание и `inputSchema` с описанием каждого параметра
- **AND** у каждого установлен признак `readOnlyHint = true`

#### Scenario: Описание подсказывает порядок использования
- **WHEN** агент читает описания инструментов
- **THEN** описание `get_current_price` и `get_price_history` указывает, что тикер (`secid`) следует получать через `search_securities`, если пользователь назвал бумагу по названию или ISIN

#### Scenario: Режим расписания включён
- **WHEN** клиент вызывает `list_tools` у сервера, запущенного с `--watch-db`
- **THEN** ответ содержит три инструмента чтения с `readOnlyHint = true` и шесть инструментов расписания без этого признака

### Requirement: Локальный запуск и транспорты
Сервер SHALL запускаться командой `mcp-moex` без каких-либо обязательных настроек, ключей или учётных данных. По умолчанию сервер MUST использовать транспорт `stdio`. По явному указанию сервер SHALL работать по Streamable HTTP, при этом MUST принимать соединения только на loopback-адресе `127.0.0.1`. Сервер MUST допускать запуск клиентом в виде `uv run --directory <путь к проекту> mcp-moex`. Сервер SHALL принимать необязательный аргумент `--watch-db <путь>`, включающий режим расписания с хранилищем по этому пути (с любым из транспортов); без него сервер MUST NOT создавать и открывать файлов хранилища.

#### Scenario: Запуск по умолчанию
- **WHEN** агент запускает `mcp-moex` без аргументов как подпроцесс
- **THEN** сервер общается с агентом по `stdio` и не открывает сетевых портов
- **AND** не создаёт файлов на диске

#### Scenario: Запуск по HTTP
- **WHEN** сервер запущен с указанием транспорта Streamable HTTP
- **THEN** он слушает только `127.0.0.1`
- **AND** недоступен с других сетевых интерфейсов

#### Scenario: Запуск в режиме расписания
- **WHEN** клиент запускает `mcp-moex --watch-db <путь>` по `stdio`
- **THEN** сервер публикует инструменты расписания и хранит данные по указанному пути
