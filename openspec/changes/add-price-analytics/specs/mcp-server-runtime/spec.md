## MODIFIED Requirements

### Requirement: Регистрация инструментов
Сервер SHALL публиковать через `list_tools` по умолчанию ровно шесть инструментов:
`search_securities`, `get_current_price`, `get_price_history`, `compute_price_metrics`,
`compare_with_benchmark` и `compare_securities`. Каждый инструмент MUST иметь текстовое
описание, объясняющее для чего он нужен и когда его применять, и JSON-схему входных
параметров с типами, описаниями, допустимыми значениями перечислений, значениями по
умолчанию и границами. Все шесть инструментов MUST быть помечены как только читающие
(`readOnlyHint`), сервер SHALL NOT выполнять никаких действий, изменяющих внешние
системы. Только при явном включении режима расписания (флаг `--watch-db`) сервер SHALL
дополнительно публиковать шесть инструментов расписания (см. возможность
`moex-price-watch`): они изменяют лишь локальное хранилище сервера, не помечены как
только читающие и не относятся к шести инструментам чтения, чьё поведение режим не
меняет.

#### Scenario: Клиент запрашивает список инструментов
- **WHEN** клиент вызывает `list_tools` у сервера, запущенного без `--watch-db`
- **THEN** ответ содержит шесть инструментов с именами `search_securities`, `get_current_price`, `get_price_history`, `compute_price_metrics`, `compare_with_benchmark`, `compare_securities`
- **AND** у каждого есть описание и `inputSchema` с описанием каждого параметра
- **AND** у каждого установлен признак `readOnlyHint = true`

#### Scenario: Описание подсказывает порядок использования
- **WHEN** агент читает описания инструментов
- **THEN** описание `get_current_price` и `get_price_history` указывает, что тикер (`secid`) следует получать через `search_securities`, если пользователь назвал бумагу по названию или ISIN
- **AND** описания `compute_price_metrics`, `compare_with_benchmark` и `compare_securities` указывают, что историю следует получать через `get_price_history`

#### Scenario: Режим расписания включён
- **WHEN** клиент вызывает `list_tools` у сервера, запущенного с `--watch-db`
- **THEN** ответ содержит шесть инструментов чтения с `readOnlyHint = true` и шесть инструментов расписания без этого признака

### Requirement: Проверка смоук-клиентом
Проект SHALL включать смоук-клиент, использующий MCP SDK: он запускает сервер по `stdio`,
вызывает `list_tools` и вызывает каждый из шести инструментов на реальных данных, при
этом результаты `get_price_history` передаёт в `compute_price_metrics`,
`compare_with_benchmark` и `compare_securities` без изменений, печатает результаты и
завершается ненулевым кодом, если любой шаг не удался.

#### Scenario: Успешная проверка
- **WHEN** запущен смоук-клиент при доступном ISS
- **THEN** он выводит список инструментов и результаты вызовов поиска, текущей цены, истории, метрик, сравнения с индексом и сравнения двух акций
- **AND** завершается с кодом 0

#### Scenario: Сбой проверки
- **WHEN** любой из вызовов возвращает ошибку или сервер не запускается
- **THEN** смоук-клиент завершается с ненулевым кодом и указывает, какой шаг не удался
